# 资源占用测量

2026-10-10，对当前已运行的流量喵 1.3.3 进行一次短时观察，不更改用户的暂停或面板状态。机器为 Apple M1（MacBookPro17,1），macOS 26.5.2。

## 方法

- 每 2 秒读取 `ps -p PID -o time=,rss=,%cpu=`，共 60 秒。使用累计 CPU 时间的首尾差除以实际经过时间，计算主进程平均 CPU；不是直接取 ps 的历史 `%cpu`。
- RSS 由 KiB 转成 MiB，取所有观察值的最小／最大值。
- 单独执行 3 轮当前采样命令：`nettop -P -L 1 -n -J bytes_in,bytes_out`、`netstat -ibn`、`ps -axo pid=,comm=`。通过 Python `resource.getrusage(RUSAGE_CHILDREN)` 的 CPU 时间增量统计各轮子进程成本，再按 10 秒采样间隔估算平均 CPU。
- CPU 百分比以单核 100% 为基准；主进程与额外测量的命令相加只是合计估算，不是同时追踪整个进程树的基准测试。

## 原始结果

| 指标 | 数值 |
| --- | --- |
| 主进程观察时长 | 60.44 秒 |
| 主进程平均 CPU | 0.69% |
| 主进程 RSS | 102.8–106.9 MiB |
| 命令第 1 轮 CPU 时间／经过时间 | 0.072898 秒／0.083168 秒 |
| 命令第 2 轮 CPU 时间／经过时间 | 0.082918 秒／0.097242 秒 |
| 命令第 3 轮 CPU 时间／经过时间 | 0.068768 秒／0.084890 秒 |
| 命令平均 CPU 估算 | 0.75% |
| 主进程 + 命令平均 CPU 估算 | 约 1.4% |
| 本机构建应用的磁盘占用 | 1048 KiB（du -sk；约 1 MiB） |
| 本地安装 ZIP 大小 | 257217 字节（约 251 KiB） |

RSS 不是活动监视器全部内存指标的同义词，也没有覆盖采样子进程的内存峰值。磁盘占用不包括历史文件。安装包来自本地构建，与 CI 产物可能略有区别。

一次短时观察不能代表所有机器、连接量、面板操作或长期数据规模，也未测量能耗和电池续航。当前 CPU 较低，主进程内存约百 MiB；不宣传“零开销”或“只占几 MB”。

## 1.3.4 优化复测

减少后台常驻视图与原始图标：面板按需创建并在关闭后释放；仅为列表显示项加载 64×64 像素图标，最多 64 个，关闭后清空；采样工作使用局部 autorelease pool。没有改变采样间隔、统计规则或历史保存路径。

同一 M1 机器、同一历史文件：优化构建重启后观察 60.42 秒，RSS 46.1–119.8 MiB（含启动阶段），主进程 CPU 1.34%（含启动），约一分钟时 vmmap Physical footprint 36.4M、峰值 46.5M。随后重启原版 1.3.3，后台 0／20／40／60 秒读数为 RSS 117.6／122.1／122.5／114.3 MiB，Physical footprint 41.6／42.7／38.1／38.1M。

不是随机交替、长时间、多机器基准，采样时间点也不完全一致。可以确认新版后台不再加载整套面板和原始图标；这次物理内存降幅有限，不能宣传大幅降低或只有几 MB。RSS 包含共享映射，不能直接当作独占物理内存。

本地构建和 30 项统计检查通过。图形自动化未获该应用访问权限，面板反复开关和图标显示的现场回归尚未完成。
